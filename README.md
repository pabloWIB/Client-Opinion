# Client Opinion

A clean testimonial section component featuring Google Reviews integration and client feedback display. Perfect for flower shops, local businesses, and service providers wanting to showcase customer satisfaction.

## Tech Stack

- **HTML5** - Structure and content
- **CSS3** - Styling and responsive design  
- **Vanilla JavaScript** - Interactive features
- **Static Files Only** - No backend required

## Features

- **Google Reviews Integration** - Display authentic customer feedback
- **Responsive Testimonials** - Works on all devices
- **Clean Design** - Professional appearance with Google branding
- **Star Ratings** - Visual feedback display
- **Customer Photos** - Optional profile images
- **Easy Customization** - Simple to modify and update

## Quick Start

1. **Download**
   ```bash
   git clone https://github.com/pabloWIB/Client-Opinion.git
   cd Client-Opinion
   ```

2. **Open**
   - Double-click `index.html`
   - Or drag file into browser
   - Ready to use immediately

## Deployment

**Upload to any web host:**

- **Netlify** - Drag folder to netlify.com
- **GitHub Pages** - Push to GitHub, enable Pages
- **Any Web Host** - Upload via FTP
- **Surge.sh** - `surge` command

## Customization

**Update Reviews:**
- Edit testimonials in `index.html`
- Add customer names and feedback
- Update star ratings

**Change Styling:**
- Modify `css/style.css`
- Update colors and fonts
- Adjust layout spacing

**Add Features:**
- Edit `js/testimonials.js`
- Add review carousel
- Include filtering options

## Integration

**For Flower Shops:**
- Perfect for showcasing bouquet orders
- Display delivery satisfaction
- Highlight special occasion feedback

**For Any Business:**
- Drop into existing websites
- Standalone testimonial page
- Marketing material component

## Browser Support

Works in all modern browsers. No dependencies.
